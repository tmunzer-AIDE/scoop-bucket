# tmunzer-AIDE Scoop bucket

Scoop manifests for [mistctl](https://github.com/tmunzer-AIDE/mistctl), a
read-only, kubectl-style command line client for the Juniper Mist API.

```powershell
scoop bucket add mistctl https://github.com/tmunzer-AIDE/scoop-bucket
scoop install mistctl
```

`mistctl.json` is generated by GoReleaser on every mistctl release. Do not
edit it by hand.
